# 픽셀스튜디오 회사 사이트

픽셀스튜디오의 회사 홈페이지입니다. 빌드 과정이 없는 정적 사이트라, 파일을 고쳐서 올리면 그대로 반영됩니다.
Link 앱의 서버·저장소와는 따로 관리합니다(회사 사이트를 고친다고 서비스를 다시 배포하지 않습니다).

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 사이트 전체(회사 소개 → 서비스 → 안전 → 고객지원 → 회사 정보) |
| `assets/styles.css` | 스타일. 색은 맨 위 `:root`의 변수와 `.c-*` 클래스에 모여 있습니다 |
| `assets/pixel-field.svg` | 첫 화면의 픽셀 그림 |
| `assets/shot-*.jpg` | 서비스(Link) 칸의 앱 화면 |
| `404.html` | 없는 주소로 들어왔을 때 |

## 고칠 때 지킬 것

- **회사의 사이트입니다.** Link 앱의 보라색·말풍선 로고는 '서비스' 칸 안에서만 씁니다.
- **외주 포트폴리오처럼 읽히는 구성을 넣지 않습니다** — 하는 일(기획·디자인·개발), 작업 과정, 쓰는 기술, 제휴 문의 같은 것.
- **회사 정보에는 상호·대표자·사업자등록번호·이메일만 적습니다.** 주소와 전화번호는 넣지 않습니다
  (전체 사업자 정보는 Link의 약관 및 정책 페이지에 있습니다). 통신판매업 신고번호가 나오면 한 줄 추가합니다.
- 확인할 수 없는 숫자(이용자 수 등)는 적지 않습니다.
- 스크립트를 쓰지 않습니다. `index.html`의 보안 정책(CSP)이 같은 저장소의 스타일·그림만 허용합니다 —
  바깥 글꼴·스크립트·그림을 넣으면 표시되지 않습니다. 태그에 `style="…"`을 직접 쓰는 것도 막혀 있으니 클래스를 씁니다.
- 약관·정책 링크는 Link 서비스 서버(`https://api.public-link.cloud/api/policies/…`)를 가리킵니다.

## 미리 보기

```
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

```

```
